KOROLEV — многостраничный статический сайт

Содержимое:
- index.html — главная
- services.html — услуги
- portfolio.html — портфолио
- prices.html — цены
- about.html — о студии
- reviews.html — отзывы
- contacts.html — контакты и форма заявки
- assets/style.css — оформление
- assets/main.js — меню и форма
- robots.txt и sitemap.xml — базовая SEO-техническая настройка

Публикация бесплатно через GitHub Pages:
1. Создай публичный репозиторий на GitHub.
2. Загрузи ВСЕ файлы и папку assets, сохрани структуру.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Через некоторое время сайт будет доступен по адресу вида https://USERNAME.github.io/REPOSITORY/.
5. После публикации замени адрес korolev.github.io в canonical, JSON-LD, sitemap.xml и robots.txt на настоящий адрес сайта.

SEO:
- В страницах есть уникальные title/description, заголовки, alt-тексты и JSON-LD.
- Добавь сайт в Google Search Console и Яндекс Вебмастер и отправь sitemap.xml.
- Для локального поиска укажи реальный город/регион обслуживания и создай профиль организации, если применимо.
- Не обещается мгновенное попадание в топ: поисковая видимость зависит от контента, конкуренции, возраста сайта и внешних сигналов.

Форма:
Форма собирает текст в браузере и открывает Telegram с подготовленным сообщением. Посетитель должен сам нажать «Отправить». Для полностью автоматической отправки нужен Telegram-бот или внешний form-сервис, который потребует отдельной настройки.

Портфолио:
Изображения на страницах — демонстрационные референсы с Unsplash, не реальные проекты KOROLEV. Заменить на собственные работы до публикации.

Важно:
Сейчас адрес korolev.github.io — пример-заглушка, не подтверждённый свободный адрес GitHub. При публикации используй свой GitHub username и имя репозитория.
